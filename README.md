Launch Radar ranks the protocols that record no token yet by an implied value figured from the snapshot's own figures: each category's trading multiple, learned from the protocols whose tokens already trade, times the protocol's TVL, adjusted for seven-day growth, for how long it has run, and for how many chains it runs on. Every row carries a concrete farm plan with costs and times, and the dashboard is sortable, filterable, and has a detail view for each protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
